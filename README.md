# R/D — source

This `source` branch holds the editable code, tests and tools for R/D, the retinal detachment drawing app.
The `main` branch holds only the built website that GitHub Pages serves at
**https://anthonyjohnob.github.io/R-D/** (the address is case-sensitive).

## Layout

| Path | What it is |
| --- | --- |
| `src/core.js` | Chart geometry, the dictation parser, hand-drawn detachments, tumour descriptors (size, thickness, elevation, drusen, orange pigment, SRF), repair-evidence scoring, review links (pack/diff/sanitise) |
| `src/changelog.js` | Version number and the update list shown in the app (newest first); add an entry for every published update |
| `src/buckle.js` | Scleral buckle guide: configuration for the drawn breaks (buckle alone, or with vitrectomy), element library, cited evidence |
| `src/render.js`, `src/render-cat.js` | Canvas drawing of the fundus chart and the pathology library |
| `src/hand.js` | Drawing by hand: tracing borders, palette, drag/tap placement |
| `src/app.js` | Page logic: panels, dictation, teaching review, saving/export |
| `src/catalog.js` | Pathology catalogue (generated by `tools/gen_catalog.js` from `research/catalog.json`) |
| `src/page.html`, `src/style.css`, `src/logo.svg` | Page template, styles, logo |
| `site/` | Website-only files: self-hosted fonts, icons, manifest, service worker, privacy section |
| `research/` | Literature sets and verified references behind the catalogue and repair options |
| `test/` | Node unit tests (`node test/<name>.test.js`) |
| `scratch/*.py` | Browser checks with Playwright (hand drawing, teaching review, website/offline, render fuzz) |
| `tools/` | Catalogue builders, icon/preview renderer, `publish.sh` |

## Build and check

```
python3 build.py                      # → dist/R-D.html (standalone), dist/artifact/, dist/site/ (website)
for t in test/*.test.js; do node $t | tail -1; done
python3 scratch/site_test.py          # needs Playwright + Chromium
python3 scratch/hand_e2e.py; python3 scratch/review_e2e.py; python3 scratch/tumor_e2e.py; python3 scratch/buckle_e2e.py; python3 scratch/breaks_e2e.py; python3 scratch/handtools_e2e.py
```

## Publish

Add an entry to `src/changelog.js` first (1.x steps for features, 1.x.y for fixes; version 2 only when the owner says so).
`tools/publish.sh` builds, runs the checks, refuses a version that is already live, and copies `dist/site/` into a checkout of `main`.
Commit and push from that checkout; Pages redeploys in a minute or two.
Commits use the GitHub no-reply address `316361126+anthonyjohnob@users.noreply.github.com`.

The website makes no third-party requests and has no "Ask Claude" option; dictation runs on the device where the browser supports it.
